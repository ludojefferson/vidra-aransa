# Vidraçaria NSA - Landing Page Profissional

Esta é uma landing page moderna e responsiva desenvolvida para a **Vidraçaria NSA**, uma empresa especializada em soluções de vidros e espelhos em São Paulo. O projeto foi construído com foco em performance, SEO e conversão de clientes.

## 🚀 Tecnologias Utilizadas

O projeto utiliza as tecnologias mais atuais do ecossistema JavaScript para garantir uma interface rápida e fluida:

* **React / Next.js** - Framework para renderização híbrida e rotas eficientes.
* **Tailwind CSS** - Estilização moderna com foco em utilitários e design responsivo.
* **Lucide React** - Conjunto de ícones leves e elegantes.
* **Vercel** - Plataforma de deploy e hospedagem com integração contínua.

## ✨ Funcionalidades

* **Design Mobile-First:** Totalmente otimizado para visualização em smartphones e tablets.
* **Galeria de Serviços:** Exibição detalhada de serviços como Box para Banheiro, Espelhos Decorativos e Sacadas Articuladas.
* **Integração com WhatsApp:** Botões de chamada para ação (CTA) direcionando o usuário para o atendimento direto.
* **Localização Integrada:** Seção "Onde Estamos" com integração para rotas de GPS.
* **SEO Otimizado:** Estrutura de tags e metadados configurada para melhor visibilidade em motores de busca.
